# Invitation — Miya & Neyl 🐉🦄

L'invitation d'anniversaire des jumeaux Miya & Neyl, à ouvrir sur un téléphone.

👉 **https://diezzoul.github.io/invitation-miya-neyl/**

Une page unique, sans dépendance : tout tient dans `index.html`
(dessins en SVG, jeux en JavaScript, aucune bibliothèque à installer).

Pour modifier les informations (prénoms, date, adresse, téléphone) :
ouvre `index.html` et cherche `const INVITATION`, tout en haut du script.

## Mise en ligne

Le site est servi par GitHub Pages depuis la branche `main`, à la racine.
Réglage : *Settings → Pages → Source : Deploy from a branch → main → / (root)*.
